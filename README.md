# Stream Duo support

Public privacy and support information for Stream Duo.

- [Support](https://gamedesigner.github.io/streamduo-support/support.html)
- [Privacy policy](https://gamedesigner.github.io/streamduo-support/privacy.html)
- [Ask a question or report a bug](https://github.com/Gamedesigner/streamduo-support/issues/new/choose)

Support requests here are public. Never post stream keys, passwords, payment information, private recordings or personal data. For Apple purchase refunds, use Apple's purchase support tools. This repository contains public support content only, not the app source.
